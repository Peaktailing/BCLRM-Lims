## BioManager 1.10.1

### Fixed

- **The phone keeps each litter of a Breeding cage.** Working offline, a cage showed only its first litter, and **Wean** always weaned the oldest. Now the cage lists every litter not yet weaned; **Litter born** asks **Another litter** or which one to correct, and takes the pups and the mother; **Genotyping** and **Wean** ask **Which litter**, the oldest first, as the pages do. A litter recorded, corrected or weaned on another computer now reaches the phone too, and these choices show in Chinese on a Chinese phone.
  - **手机会保留繁殖笼的每一窝。** 以前离线时，笼子只显示第一窝，**断奶** 总是给最早的一窝断奶。现在笼子会列出每一窝尚未断奶的幼崽；**产仔** 会问是 **另一窝** 还是更正哪一窝，并记录仔数和母鼠；**基因型鉴定** 和 **断奶** 会问 **哪一窝**，最早的排在前面，和网页上一样。在别的电脑上记录、更正或断奶的一窝也会同步到手机，中文手机上这些选项也显示中文。

### Website

- The *Record a litter* clip in the user guide shows a second litter being recorded.
  - 用户指南里 *记录产仔* 的短片演示了记录第二窝的过程。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.10.1, or download it below. Your data is kept outside the app.
- **Android app**: download `BioManager-Android.apk` below and install it over the old one.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first. The server needs this version for phones to see a cage's litters.

  This version changes nothing in the database.
