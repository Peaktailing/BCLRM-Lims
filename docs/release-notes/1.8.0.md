## BioManager 1.8.0

### New

- **Verify sequencing.** On a plasmid's **Sequence** tab, **Verify sequencing** checks Sanger reads of a miniprep or clone against its map. Choose the `.ab1` chromatograms (or paste the bases) and it places each read on the plasmid, on either strand and across the origin, and trims the poor ends. It lists every mismatch, insertion and deletion with the quality there, the features it falls in and what it does to a protein (silent, a changed amino acid, a stop, a frameshift), then gives a verdict for each read and for the clone. **Keep the reads and the result with this plasmid's files** keeps them for later.
  - 核对测序结果：在质粒的 **序列** 标签页，**核对测序结果** 把小提或克隆的 Sanger 测序结果与质粒图谱比对：列出每处错配、插入和缺失、所在特征和对蛋白的影响，并给出每条读段和整个克隆的结论。
- **Readouts BioManager works out from what you measure.** An experiment's readout can be a tumour volume from caliper length and width (L × W² / 2, or from three diameters), ΔCt, ΔΔCt and fold change against a control group, a percentage of a baseline, or blank-subtracted absorbance. You enter the measurements (in the sheet, the dialog or **Bench mode**) and BioManager stores the value, keeping the measurements with it and in the export.
  - 由 BioManager 根据测量值计算的观测指标：卡尺测的肿瘤体积、ΔCt、ΔΔCt 和倍数变化、相对基线的百分比、扣除空白的吸光度。你输入测量值，BioManager 算出并保存结果，测量值也一并保留。
- **Pack size.** A reagent kept in ampoules, vials or bottles can say what one holds ("10 mL"), so using 2 mL takes 0.2 ampoules off.
  - 包装规格：按安瓿、瓶等计数的试剂可以写明每个装多少（“10 mL”），用掉 2 mL 就会扣掉 0.2 个安瓿。
- **For AI assistants:** an **animal-use report** for an IACUC or animal-care annual review (animals per protocol, species and strain: born, added, used, died or euthanized with reasons, breeding, with what each count is based on); a **handover** of everything someone leaving looks after; derived readouts; sequencing verification from reads uploaded as **Captures**; and a plasmid's glycerol stocks.
  - AI 助手新增：动物伦理年度审查用的 **动物使用报告**、成员离开时的 **交接清单**、计算观测指标、用上传为 **速记** 的测序结果做验证，以及质粒的甘油菌。
- **The plugin as downloads.** The website's Download page has **Plugin for Claude** and **Plugin for ChatGPT**, and every release carries them. The website also has a privacy page and terms.
  - 插件可直接下载：网站下载页新增 **Claude 插件** 和 **ChatGPT 插件**，每个版本都附带；网站也新增了隐私和使用条款页面。

### Works differently

- **For scripts using the API:** `GET /api/v1/plasmids/<n>` leaves out the DNA sequence and its annotations unless you ask with `?sequence=1`. It now has `length` and `glycerol_stocks`. Litters in `GET /api/v1/litters` have their `cage`, and `?cage=` lists a cage's litters.
  - 使用 API 的脚本请注意：`GET /api/v1/plasmids/<n>` 默认不再返回 DNA 序列和注释，需要时加 `?sequence=1`。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.8.0, or download it below. Your data is kept outside the app, and a copy is taken before the database is upgraded.
- **Lab server on 1.2.6 or later**: **Settings → Devices & copies → Updates → Update now**. It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  The database upgrades itself on start: inventory items gain a pack size, empty until you set one. Nothing already there changes, and every earlier release's database was checked to upgrade with nothing lost. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
