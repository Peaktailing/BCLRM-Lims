## BioManager 1.8.1

### Fixed

- **The animal-use report counts today's animals wherever the lab is.** Outside UTC, a mouse or fish entered late in the day, or a sac logged then, could fall outside the period and be left out. Each is now counted on the lab's own day.
  - 动物使用报告按实验室所在时区计算日期：之前在 UTC 以外的地区，当天晚些时候录入的小鼠或斑马鱼、或当时记录的处死，可能被算到期间之外。
- **Behind the scenes:** the sequencing-check tests run on PostgreSQL as well as SQLite, as lab servers do.
  - 测序核对的测试现在也在 PostgreSQL 上运行，与实验室服务器一致。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.8.1, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Devices & copies → Updates → Update now**. It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version changes nothing in the database. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
