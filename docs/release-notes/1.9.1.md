## BioManager 1.9.1

### Fixed

- **The desktop app shows its pages styled again on a Mac when it works on a lab server.** After **Open your lab**, the window showed every page without its look: huge icons, plain links and no layout. The app now passes on the server's pages exactly as the server sends them. The app on its own, phones and browsers were not affected.
  - **在 Mac 上，桌面应用连接实验室服务器时，页面样式恢复正常。** 用 **打开你的实验室** 加入后，窗口里的每个页面都没有样式：图标很大、链接是普通文字、没有排版。现在应用会原样转交服务器发来的页面。单独使用的桌面应用、手机和浏览器都不受影响。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.9.1, or download it below. Your data is kept outside the app. If the window is unstyled and you can't find the menu, use **BioManager → Check for Updates…** in the Mac's menu bar.
- **Lab server**: nothing changes on the server in this version, so it can stay on 1.9.0. To update anyway, **Settings → Version → Update now**; it backs up first.

  This version changes nothing in the database.
