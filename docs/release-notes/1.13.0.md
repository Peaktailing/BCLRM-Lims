## BioManager 1.13.0

### New

- **Samples by type.** Samples has a tab for each type above the sheet: **All**, then **tissue**, **blood**, **serum**, **DNA**, **RNA**, **protein** and the rest. A tab lists that type with only its own columns and the boxes that hold it: tissue has the new **Tissue**, **Fixation** and **Orientation**, DNA and RNA the concentration, 260/280, 260/230 and volume. A new sample from a tab is of that type, and its dialog asks only for that type's columns. **+** at the end of the tabs adds a type, and **Used for** in **Configure** sets which columns each type has; any inventory can turn on **A tab for each type**. Every sample also has **Genotype**, which, left empty, shows the source mouse's from the colony, and **Condition**.
  - **按类型管理样本。** 样本库在表格上方为每种类型设了一个标签页：**全部**，然后是 **组织**、**血液**、**血清**、**DNA**、**RNA**、**蛋白** 等。每个标签页只列出该类型的样本，只显示它自己的列和装着它的冻存盒：组织有新增的 **组织**、**固定方式** 和 **切面方向**，DNA 和 RNA 有浓度、260/280、260/230 和体积。在某个标签页里新建的样本就是那种类型，对话框也只问该类型的列。标签页最后的 **+** 用来添加类型，**配置** 里的 **用于** 决定每种类型有哪些列；任何库存都可以勾选 **每种类型一个标签页**。每个样本还有 **基因型**（留空时显示来源小鼠在小鼠群里的基因型）和 **处理条件**。
- **Split notes.** Samples brought in from another database with everything in the notes (*Tissue: Lung; Fixation: 4% PFA; control 2w*): tick them and **Split notes** moves each *Column: value* into the column of that name, leaves the rest in the notes, and lists any name with no column. **Batch history** undoes it.
  - **拆分备注。** 从别的数据库导进来、所有内容都在备注里的样本（*Tissue: Lung; Fixation: 4% PFA; control 2w*）：勾选后点 **拆分备注**，每个“列名: 值”会移到同名的列，其余留在备注里，没有对应列的名称会列出来。**批量操作记录** 可以撤销。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.13.0, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  The database upgrades itself on start: each Samples database gets its type tabs and the new Tissue, Genotype, Condition, Fixation and Orientation columns, and its measured columns are marked for DNA, RNA and protein. No table changes and nothing already entered changes; every earlier release's database was checked to upgrade with nothing lost. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
