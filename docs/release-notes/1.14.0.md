## BioManager 1.14.0

### New

- **A measure can be ΔCt, ΔΔCt or fold change.** **Another measure…** in **Plate layout** now asks its **Kind**: **A number**, or a value from two genes' Cts, against a **Control group** for ΔΔCt and fold change. So one qPCR run can put a gene's ΔCt beside tumour volume. On the sheet, a Ct measure's cell takes the two Cts ("24.8 − 18.2"), and a ΔCt measure also takes the ΔCt itself. **Export** adds the Ct columns.
  - **指标可以是 ΔCt、ΔΔCt 或倍数变化。** **孔板布局** 里的 **其他指标…** 现在会问它的 **类型**：**数值**，或由两个基因的 Ct 算出的值，ΔΔCt 和倍数变化还要相对一个 **对照组**。这样一次 qPCR 就能在肿瘤体积旁边填上某个基因的 ΔCt。在表格上，Ct 类指标的格子可以填两个 Ct（“24.8 − 18.2”），ΔCt 指标也可以直接填 ΔCt。**导出** 会加上 Ct 列。
- **Rename or delete a measure.** With a measure chosen on the sheet, the **•••** beside it opens **Measure**: its name and unit, and **Delete measure**, which says first how many readings go with it. **Batch history**'s **Undo** brings back a deleted measure with its readings.
  - **指标可以改名或删除。** 在表格上选中一个指标后，旁边的 **•••** 会打开 **指标**：可以改名称和单位，也可以 **删除指标**，删除前会先说明有多少条读数会一起删除。**批量操作记录** 里的 **撤销** 会把删掉的指标连同读数一起恢复。
- **Bench mode records other measures too:** its first screen lists the main readout, then a big button for each measure.
  - **实验台模式也能记录其他指标：** 第一屏先列出主要观测指标，再为每个指标各放一个大按钮。

### Works differently

- **The notebook's experiment block is in Chinese** on a Chinese page, every word of it, and can show any of the experiment's measures, not just the main readout; the choice is kept with the block.
  - **笔记本里的实验块在中文页面上全部显示中文**，并且可以显示实验的任何一个指标，而不只是主要观测指标；所选的指标会随这个块一起保存。
- **Reading a qPCR plate, a housekeeping gene on the run (Gapdh, Actb, B2m, Hprt, 18S…) starts as the reference gene,** so the target and reference no longer come the wrong way round when the reference sorts first.
  - **读取 qPCR 板时，运行里的管家基因（Gapdh、Actb、B2m、Hprt、18S……）默认作为内参基因**，内参基因按字母排在前面时，目的基因和内参基因不会再颠倒。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.14.0, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version changes nothing in the database's tables. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
