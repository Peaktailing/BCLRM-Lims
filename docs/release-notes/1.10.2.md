## BioManager 1.10.2

### Works differently

- **The anonymous daily counts have a switch in Settings → General.** **Share anonymous counts with BioManager's makers** is there for admins, beside the lab's name and time zone, and says what the counts are for: BioManager is free, and they are how its makers can show that labs rely on it and see which parts to improve first. **Switch off** on the Usage report still works, and *See exactly what is sent* shows the message word for word.
  - **每天的匿名统计在“设置 → 一般”里有了开关。** 管理员可以在实验室名称和时区旁边找到 **与 BioManager 开发者分享匿名统计**，并能看到这些统计的用处：BioManager 是免费的，开发者靠它们说明有实验室在依靠它，并知道该先改进哪些部分。使用报告里的 **关闭** 依然可用，*查看发送的确切内容* 会逐字显示发送的消息。
- **A new lab's setup no longer asks about the counts.** They are on, and the setup survey says so in a line, with where to switch them off. A lab that switched them off keeps them off.
  - **新实验室设置时不再询问匿名统计。** 统计默认开启，设置问卷里有一句说明，并告诉你在哪里关闭。已经关闭的实验室保持关闭。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.10.2, or download it below. Your data is kept outside the app.
- **Android app**: download `BioManager-Android.apk` below and install it over the old one.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.

  This version changes nothing in the database.
