## BioManager 1.8.2

### New

- **Weaning day** in **Settings → General** (and the lab setup survey), beside **Genotyping day**: the day after birth a litter is due to be weaned, P21 unless your lab chooses another. The cage's **Wean due** date, Home, the calendar and the reminders all follow it, and weaning on your lab's own day never asks whether the pups are too young.
  - **设置 → 一般**（以及实验室设置问卷）里新增 **断奶日**，在 **基因型鉴定日** 旁边：出生后第几天该断奶，默认 P21，实验室可以改。笼子上的 **应断奶** 日期、首页、日历和提醒都按它来算；在实验室自己定的那天断奶，不会再问幼崽是否太小。

### Works differently

- **Setting up a lab server:** the **Setup code** field says how to see the code: `docker compose logs app | grep "setup code"`, run on the server in BioManager's deploy folder.
  - **搭建实验室服务器时**，**设置码** 一栏会说明怎样查看它：在服务器上 BioManager 的 deploy 文件夹里运行 `docker compose logs app | grep "setup code"`。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.8.2, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version changes nothing in the database. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
