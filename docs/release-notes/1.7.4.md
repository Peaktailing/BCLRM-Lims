## BioManager 1.7.4

### New

- **The BioManager plugin as a download.** Every release now has `BioManager-plugin-Claude.zip` (the whole plugin, for Claude's **Add → Upload plugin**) and `BioManager-plugin-ChatGPT.zip` (its skills, to upload for ChatGPT), and the Download page has a card for them. The guide's *Connect an AI assistant* says how to install from the download.
  - BioManager 插件现在可以直接下载：每个版本都附带 `BioManager-plugin-Claude.zip`（完整插件，用于 Claude 的 **添加 → 上传插件**）和 `BioManager-plugin-ChatGPT.zip`（其中的技能，上传给 ChatGPT），下载页面也有对应的卡片。用户指南的“连接 AI 助手”写了怎样从下载安装。

### Fixed

- **Allow did nothing when connecting an assistant.** On the sign-in page an assistant app opens (Claude Code, ChatGPT, Cursor and others), pressing **Allow** now goes back to the app and connects it; before, the browser quietly refused to go on.
  - 连接 AI 助手时点 **允许** 没有反应：现在会回到那个应用并完成连接（Claude Code、ChatGPT、Cursor 等）；以前浏览器会悄悄拒绝跳转。
- **Help → What's new said "Nothing to tell about this version"** on a lab server built from its source code, which doesn't know its own version. It now shows the newest notes.
  - 从源代码搭建的实验室服务器不知道自己的版本，**帮助 → 新功能** 会显示“这个版本没有要特别说明的”；现在会显示最新的新功能说明。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.7.4, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Devices & copies → Updates → Update now**. It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  The database doesn't change in this release.
