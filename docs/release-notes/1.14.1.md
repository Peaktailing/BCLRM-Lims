## BioManager 1.14.1

### New

- **Kimi Code takes the BioManager plugin.** In Kimi Code, `/plugins install https://github.com/gaspolymerase/biomanager/releases/latest/download/BioManager-plugin-Kimi.zip` adds it: the skill that teaches it to work with BioManager, and the nine prompts as commands, such as `/biomanager:log-today`. Then add your BioManager's address with `/mcp-config` and sign in with `/mcp-config login biomanager`. The steps are in the guide's *Connect an AI assistant*, under *Qwen Code and Kimi Code*. Every release now carries `BioManager-plugin-Kimi.zip`.
  - **Kimi Code 也能添加 BioManager 插件了。** 在 Kimi Code 里，`/plugins install https://github.com/gaspolymerase/biomanager/releases/latest/download/BioManager-plugin-Kimi.zip` 就能添加：教它使用 BioManager 的技能，以及作为命令的九个提示词，比如 `/biomanager:log-today`。然后用 `/mcp-config` 添加你的 BioManager 地址，再用 `/mcp-config login biomanager` 登录。步骤在用户指南的“连接 AI 助手”里，“Qwen Code 和 Kimi Code”一节。现在每个版本都附带 `BioManager-plugin-Kimi.zip`。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.14.1, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version changes nothing in the database's tables. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
