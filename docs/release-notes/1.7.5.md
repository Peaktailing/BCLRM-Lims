## BioManager 1.7.5

### Works differently

- **Settings → Version** is a pane of its own. It says which BioManager this is, with **What's new** and the release notes, to everyone. On a lab server, the updates moved here from Devices & copies: **Check now**, **Update now** and the daily check. A server built from BioManager's source code says so, and how to update it by hand. **Devices & copies** now keeps only the devices, setting up a server and the copies of the lab.
  - **设置 → 版本** 成了单独的一页：告诉所有人这是哪个版本的 BioManager，并有 **新功能** 和版本说明。实验室服务器的更新从“设备与副本”搬到了这里：**立即检查**、**立即更新** 和每天检查的开关。从源代码搭建的服务器会说明这一点，以及怎样手动更新。**设备与副本** 现在只管设备、搭建服务器和实验室副本。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.7.5, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Devices & copies → Updates → Update now** (from this version on it is in **Settings → Version**). It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  The database doesn't change in this release.
