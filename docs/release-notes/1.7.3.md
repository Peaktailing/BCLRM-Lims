## BioManager 1.7.3

### New

- **A box can say which fridge or cabinet it is kept in** ([#58](https://github.com/gaspolymerase/biomanager/issues/58)). Every box, shelf or drawer in Samples, Reagents, Chemicals, Antibodies and the other inventories has a **Kept in** field: *Fridge 2*, *Explosion-proof cabinet*, *−80 °C freezer A*. A place typed once is offered again for every box in any database. An item's place then reads *Explosion-proof cabinet › Flammables 1 · A2* on the sheet, in its dialog, in search results and on printed labels. **Box grid** picks the place first, then the box, and searching a cabinet's name finds everything in it.
  - 每个冻存盒、架子或抽屉都可以填 **存放于**（如 2 号冰箱、防爆柜）；填过一次的地方会在其他数据库里自动提示。物品的位置显示为“防爆柜 › 易燃品 1 · A2”，表格、详情、搜索和打印标签里都一样；**冻存盒视图** 先选存放地点再选盒子；搜索柜子的名字就能找到里面所有的东西。

### Fixed

- **Searching a sheet matched every row** whose dropdowns merely offered the word: typing a box or status name found rows set to something else. It now matches only what each row has chosen.
  - 在表格里搜索时，下拉选项里出现过的词会匹配到所有行；现在只匹配每行实际选中的值。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.7.3, or download it below. Your data is kept outside the app, and a copy is taken before the database is upgraded.
- **Lab server on 1.2.6 or later**: **Settings → Devices & copies → Updates → Update now**. It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  The database gains one column (a box's Kept in), added on start; nothing else changes.
